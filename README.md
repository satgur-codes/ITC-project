# Photography Club Portfolio Page

## About the Project

The Photography Club Portfolio Page is a website designed to showcase
the best photography submissions from members of a college photography
club. It provides an attractive gallery where visitors can explore
photographs, view photographer names, enlarge images, and like their
favorite photos.

The project is developed using HTML, CSS, and JavaScript. It also
includes a client-side photo submission form.

## Features

- **Photography Gallery:** Displays photographs in an attractive grid.
- **Photographer Names:** Shows photographer names with their photos.
- **Hover Effects:** Displays an overlay with the photographer's name.
- **Image Enlargement:** Opens photographs in a modal window when clicked.
- **Like Counter:** Allows users to like individual photographs.
- **Photo Submission Form:** Provides a form to enter photo information.
- **Responsive Layout:** Uses a grid-based gallery layout for different
  screen sizes.
- **Interactive Interface:** Uses JavaScript to handle user interactions.

## Technologies Used

- **HTML5** — Structures the webpage and photography gallery.
- **CSS3** — Styles the gallery, hover effects, and modal window.
- **JavaScript** — Implements image enlargement, like counters, and
  form interactions.
- **GitHub** — Stores project files and tracks development progress.

## How to Run

Follow these steps to run the project:

1. Clone or download the project repository from GitHub.
2. Open the project folder on your computer.
3. Ensure that all HTML, CSS, JavaScript, and image files are present.
4. Open the `index.html` file in a web browser.
5. Explore the photography gallery.
6. Hover over photographs to view photographer names.
7. Click on a photograph to enlarge it.
8. Click the like button to increase the photo's like counter.
9. Use the photo submission form to enter photo information.

## Project Files

The project may use the following file structure:

- `index.html` — Main webpage containing the photography gallery.
- `style.css` — Styles the webpage and gallery layout.
- `script.js` — Handles modal interactions and like counters.
- `images/` — Contains the photography gallery images.
- `README.md` — Contains project documentation.
